## ⚙️ How to Compile & Run

You can compile and run any `.cpp` file in this repository using a standard C++ compiler like `g++`.

1. Open your terminal and navigate to the folder containing the `.cpp` file.
2. Compile the C++ file:
   ```bash
   g++ filename.cpp -o output
   ```
3. Run the compiled executable:
   - On **Windows**:
     ```bash
     .\output.exe
     ```
   - On **Linux/macOS**:
     ```bash
     ./output
     ```
